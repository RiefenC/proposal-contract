# Proposal Contract

Simple voting system smart contract built during the Rise In Solidity Fundamentals course.

The owner creates proposals with a title and description. Other users can vote to approve, reject or pass. A proposal succeeds with a two-thirds majority of approve and reject votes, pass votes count as abstentions.
